---
name: plan
description: Break a multi-file or multi-step feature into todos and implement one item at a time.
---

1. Search the repo until you know which files change.
2. Call submit_plan with the approach.
3. Write the checklist with todo_write.
4. Implement one item, mark it completed, then verify.
5. Do not start the next item until the current one is done or blocked.
